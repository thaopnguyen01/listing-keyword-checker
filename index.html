I

Purpose

The Keyword Checker Chrome Extension helps analysts quickly detect risky or relevant terms on website pages. By automatically scanning and highlighting configured keywords, it makes manual review more efficient and consistent.

II

How It Works

  • Chrome Browser Extension (Chrome, Manifest V3)
  • Runs automatically on the pages you visit.

Content Scanning

  • Walks through visible text nodes on the page.
  • Uses a keyword list (configurable by the user).
  • Highlights matches directly in the page content.
  • Shows a banner at the top listing matched terms.
  • Provides a floating panel with counts, actions, and copy-to-clipboard reporting.

Partial Matching

Matches keywords even if they appear inside larger words.

Example
supervinpocetineX matches the configured keyword vinpocetine
III

Key Features

Custom Keyword List

  • Enter one keyword per line in the pop-up or options page.

At-a-Glance Alerts

  • Banner at top: "Matches: cbd, vinpocetine, 5-htp …"
  • Panel with per-keyword counts, and Copy report.

Copy Report

  • Exports URL, total matches, matched keywords, and counts to the clipboard.

Customizable

  • Enable/disable scanning, and update keywords easily.
  • Ability to hide panel if needed.

Identifies "Not Visible" Matches

Looks for matches in the source code that may not be visible on the rendered page — for example, text that only appears inside a navigation submenu. The panel marks these with a Not Visible tag next to the keyword. This is useful when a term might be one click away, such as during an investigation.

IV

Usage

How to Install (Developer Mode)

  1. Go to the Releases page on GitHub and download the latest listing-keyword-checker.zip.
  2. Unzip the file (if it's not already unzipped).
  3. In Chrome, go to chrome://extensions/.
  4. Toggle Developer mode on (top right).
  5. Click Load unpacked → select the unzipped listing-keyword-checker folder.
  6. Visit any product listing page; the extension scans automatically.
  7. Click the toolbar icon to open the popup (toggle on/off, change highlight color, edit keywords) or open Options for a larger editor.

How to Use

  • Configure your keyword list (popup or options) — one keyword per line, to whatever you need it to be.
  • Navigate to a page — keywords highlight automatically.
  • Review the banner/panel or copy a report for audit trails.
